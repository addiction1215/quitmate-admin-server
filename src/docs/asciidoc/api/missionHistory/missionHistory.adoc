[[mission-history-detail-location]]
=== 미션 히스토리 상세 조회 (LOCATION 타입)

위치정보 열람 이력(KAN-208): 응답 `locationData.addresses` 에 좌표가 하나라도 담기면, 서버가 `admin_location_access_log` 에 한 줄을 남깁니다.
남기는 값은 관리자 userId, 회원 id, 종류(`MISSION_HISTORY_ADDRESS`), 미션 이력 id, API(`GET /api/v1/admin/mission-history/{id}`), 열람 시각(한국 시각)뿐이고 주소·좌표 값은 남기지 않습니다.
좌표가 비어 있는 응답, 다른 유형(REPLACE_ACTION·HOLD), 목록 조회, 관리자가 아닌 계정(403)은 남기지 않습니다.
이력 저장이 실패해도 응답은 그대로 200으로 나가고, 서버 로그에 좌표 없는 ERROR 한 줄이 남습니다.
