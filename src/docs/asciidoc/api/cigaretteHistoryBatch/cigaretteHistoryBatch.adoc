관리자 계정만 쓸 수 있습니다(관리자가 아니면 403). 재처리·날짜별 상태·실행 이력은 관리자 서버가 앱 서버 관리자 API를 대신 부릅니다.
앱 서버가 준 400·409는 상태와 사유(message)를 그대로 돌려주고, 앱 서버 연결·인증 실패는 502, 응답 시간 초과는 504, 앱 서버 연동 설정이 없으면 503입니다.
