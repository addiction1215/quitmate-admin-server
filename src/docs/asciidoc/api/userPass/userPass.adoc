QuitMate 90 이용권(KAN-143). 관리자 계정만 쓸 수 있습니다(관리자가 아니면 403).

* 시각은 한국 시간이고 기간은 `[startsAt, endsAt)` 입니다. 시작 시각은 포함하고, 만료 시각부터는 무효입니다.
* 유효한 이용권 = `revokedAt` 이 없고 `startsAt <= 지금 < endsAt`.
* 관리자 부여는 출처 `ADMIN_GRANT` 로 만듭니다. 같은 회원·같은 상품에 회수되지 않은 이용권과 기간이 겹치면 409입니다. 앞 이용권의 `endsAt` 에 시작하면 겹치지 않습니다(연장).
* 회수는 `revokedAt` 을 지금으로 찍습니다. 이미 회수했거나 만료된 이용권은 409입니다.
