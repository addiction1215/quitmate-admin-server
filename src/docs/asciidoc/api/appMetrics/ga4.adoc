=== GA4 지표 (KAN-218)

관리자 계정만 쓸 수 있습니다(관리자가 아니면 403). GA4 Data API `runReport` 를 서비스 계정으로 여덟 번 불러 요약·날짜별·화면·플랫폼·앱 버전·플랫폼별 활성 사용자를 한 응답으로 묶습니다.

* 기간: 끝 날짜는 GA4 속성 보고 시간대 기준 **어제**(마지막으로 다 찬 날), 시작은 끝에서 period-1일 전입니다. GA4에는 `{period}daysAgo ~ yesterday` 로 보냅니다.
* DAU·WAU·MAU(`active1DayUsers`·`active7DayUsers`·`active28DayUsers`)는 `yesterday ~ yesterday` 하루로 따로 묻습니다(KAN-230). 기간 전체로 물으면 날마다의 값을 더한 숫자가 옵니다. 기간 전체 활성·신규 사용자도 이 지표와 섞지 않고 따로 묻습니다.
* `summary` 의 DAU·WAU·MAU는 모든 플랫폼(웹사이트 포함)입니다. `activeUsersByPlatform` 은 앱 전체(Android 또는 iOS)·Android·iOS·웹으로 나눈 값입니다. 앱 전체는 GA4에 Android·iOS로 걸러 따로 물어서, 두 기기를 다 쓰는 사람도 1명입니다.
* 화면·플랫폼·버전의 `displayName` 은 관리자 이름 → 기본 이름 → (화면이고 괄호로 시작하지 않으면) `[웹] 원래 값` → 원래 값 순서로 고릅니다. 이름은 캐시와 상관없이 요청마다 붙여서, 「GA4 이름 설정」에서 바꾸면 바로 보입니다(<<app-metrics-ga4-display-names>>).
* 결과는 period별로 1시간 동안 서버 메모리에 담아 둡니다. `fetchedAt` 은 GA4를 실제로 부른 시각입니다. 실패는 담지 않습니다.
* **연결 전**(서버에 속성 ID·키 파일 설정이 없음): 200 + `enabled: false`, 나머지는 `null`·빈 배열입니다.
* **GA4 호출 실패**(권한·쿼터·네트워크·응답 이상): 503, `message` 는 `GA4_UNAVAILABLE`, `data` 는 `null` 입니다.
* `period` 가 7·28·90이 아니거나 없으면 400입니다.
