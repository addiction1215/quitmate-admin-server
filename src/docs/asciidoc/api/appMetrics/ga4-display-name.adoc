=== GA4 이름 설정 (KAN-230)

관리자 계정만 쓸 수 있습니다(관리자가 아니면 403). 「앱 지표」 GA4 칸의 화면·플랫폼·앱 버전 원래 값(`(main)/(tabs)/awards`, `web`, `(not set)` 등)에 보일 이름을 붙입니다. 앱이 보내는 값은 바꾸지 않습니다.

* 이름 고르는 순서: 관리자 이름 → 기본 이름(코드에 둔 이름표) → (화면이고 `(` 로 시작하지 않으면) `[웹] 원래 값` → 원래 값. 원래 값은 정확히 같을 때만 맞춥니다.
* 표 `ga4_display_name` 에는 관리자가 넣은 이름만 들어갑니다. 저장할 때 고친 관리자(`updatedBy`)를 남깁니다.
* 이름을 바꾸면 「앱 지표」에 바로 보입니다. GA4 숫자는 1시간 캐시해도 이름은 요청마다 붙입니다.
* `type` 은 `SCREEN`·`PLATFORM`·`APP_VERSION` 입니다. 그 밖·빈 값은 400입니다.

==== 이름 없는 값

최근 90일 GA4에 나온 값 중 관리자 이름·기본 이름이 모두 없는 것입니다. 화면·버전은 GA4 상위 200개 안에서 찾습니다. 결과는 종류별로 1시간 캐시하고, 이름은 요청마다 다시 거릅니다(이름을 넣으면 바로 빠짐). 연결 전이면 `enabled: false`, GA4 호출 실패면 503(`GA4_UNAVAILABLE`)입니다.
