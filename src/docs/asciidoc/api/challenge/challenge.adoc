[[challenge-create]]
=== 챌린지 생성

미션마다 `minHoldSeconds`(참기 미션 최소 참기 시간, 초)를 넣을 수 있습니다(KAN-194).

* 참기(`HOLD`) 미션에서만 저장합니다. 다른 종류는 값을 보내도 저장하지 않고 `null`로 둡니다(앱 서버도 참기가 아니면 이 값을 쓰지 않음).
* 비우면(`null`·생략) 앱 서버 기본값(설정 `challenge.mission.hold-default-min-seconds`, 지금 600초)을 씁니다.
* 60~86400초(1분~24시간)만 받습니다. 벗어나면 400 "최소 참기 시간은 60초(1분)부터 86400초(24시간)까지 넣을 수 있습니다."

[[challenge-update]]
=== 챌린지 수정

`missions[].minHoldSeconds`는 생략과 `null`을 구분합니다.

* 칸을 아예 보내지 않으면 기존 미션의 값을 그대로 둡니다. KAN-195 전 관리자 웹은 이 칸을 보내지 않으므로, DB에 넣어 둔 값이 수정 때 지워지지 않습니다.
* `null`을 보내면 앱 서버 기본값(지금 600초)으로 돌립니다. 숫자를 보내면 그 값으로 바꿉니다(60~86400초, 벗어나면 400).
* 새 미션(`missionId` 없음)에서 생략하거나 `null`이면 기본값입니다.
* 참기가 아닌 종류로 바꾸면 값을 비웁니다. 참기가 아닌 미션은 값을 보내도 저장하지 않습니다.
